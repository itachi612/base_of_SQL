# SQL & Data Analysis (SQLite + Pandas)

## О проекте

Проект посвящён работе с данными, хранящимися в базе данных SQLite, и их последующему анализу с использованием SQL и Pandas.  

Основная цель — отработать навыки извлечения, обработки и анализа данных, а также познакомиться с типичными задачами, которые встречаются в аналитике и Data Science.

---

## Что реализовано

В рамках проекта были выполнены следующие задачи:

- извлечение данных из базы с использованием SQL-запросов
- фильтрация и отбор нужных данных
- работа с подзапросами
- объединение таблиц (JOIN)
- построение аналитических таблиц (datamart)
- агрегация данных и вычисление метрик
- проведение простого A/B-теста
- анализ зависимости между показателями (корреляция)

### Основные задачи
1. Работа с данными из базы
выбор нужных колонок и строк
фильтрация данных на уровне SQL
2. Построение datamart
объединение нескольких таблиц
подготовка данных для анализа
3. Аналитика
расчёт метрик (min, max, avg)
анализ поведения пользователей
работа с временными данными
4. A/B тест
сравнение тестовой и контрольной группы
оценка влияния изменений на поведение пользователей
Что было отработано
написание SQL-запросов разной сложности
работа с реляционными базами данных
обработка данных в Pandas
подготовка данных для анализа
базовые методы анализа и интерпретации результатов

### Вывод

Проект позволил на практике закрепить навыки работы с SQL и Pandas, а также понять, как строится процесс анализа данных: от получения данных до формулирования выводов.
